# Inward Journey

Immersive contemplative 3D art exploring the archetypes of **Mind, Body, and Spirit** —
art as a door, not a lecture. Ethereal spaces, light, water, fog, geometric symbolism,
calm pacing. Universal, nonreligious, non-dogmatic.

## Layout

- `audio/` — finished narration tracks (dual-voice, 92 speed) + scripts + locked voice specs
- `theory/` — transcript-grounded Mind/Body/Spirit archetype theory (Law of One / L/L Research)
- `art/` — the artist's ink drawings (2014–2016), the visual reference for the series
- `prompts/` — master build prompt for the series
- `scenes/` — hand-built WebGL scenes (coming next)
